# 装備かけ手帖 — シレン6

『風来のシレン6』の装備かけを、スマホで手軽に管理する非公式Webアプリです。

推奨GitHubリポジトリ名：`shiren6-equipment-tracker`

## 機能

- 武器38種・盾33種の固定リストで収集管理
- 通常・青神器・金神器をそれぞれ収集管理
- 青神器は +5〜+10、金神器は +3〜+8 の最高補正値を記録
- 「収集済み・補正値は未確認」と未収集を区別
- 低い補正値を登録しても、既存の最高値を維持。誤入力の修正も可能
- 装備ごとの収集数、全体の収集率、最高補正の達成数を表示
- 装備名の検索、未収集・最高補正未達・3種収集済みで絞り込み
- スプレッドシートからの貼り付け・CSV取り込み
- JSONバックアップ・復元、CSV書き出し

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の構造 |
| `styles.css` | 画面のスタイルとレスポンシブ対応 |
| `app.js` | 装備データ、記録・集計・検索・インポート処理 |
| `icon.svg` | アプリアイコン |

HTML・CSS・JavaScriptのみで動作します。npm install、ビルド、APIキー、データベース、認証サーバーは不要です。

## ローカルで確認

このフォルダで、Python 3のHTTPサーバーを起動します。

```sh
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。本番はHTTPSの静的ホスティングで公開してください。

## GitHubにアップロード

1. `shiren6-equipment-tracker` というリポジトリを作成します。
2. このフォルダの中身を、リポジトリのルートにアップロードします。
3. `index.html`、`styles.css`、`app.js`、`icon.svg` が同じ階層にあることを確認します。

このソース一式にGit履歴・既存の公開先設定・利用者の収集記録は含まれません。

## 記録の保存

- 記録は各利用者のブラウザの `localStorage` に保存します。
- 利用者同士で収集データを共有しません。会員登録・ログインはありません。
- 端末・ブラウザ間の自動同期はありません。
- ブラウザのデータ削除などで記録が失われるため、「保存・設定」から定期的にJSONバックアップを書き出してください。
- 公開先のドメインやプロトコルを変更した場合、記録は自動移行されません。旧URLでバックアップし、新URLで復元してください。
- 旧版の最低補正値未満の数値は、ブラウザ内の読み込み時に「収集済み・補正未確認」へ移行します。新規入力・CSV取り込み・JSON復元では範囲外の補正値を拒否します。
- ホーム画面に追加して開けますが、オフライン起動用のService Workerは実装していません。

## スプレッドシート取り込み

以下の5列を並べ、セルをコピーして「スプシから取り込む」に貼り付けてください。CSVファイルにも対応します。

| 種別 | 装備名 | 通常 | 青神器 | 金神器 |
| --- | --- | --- | --- | --- |
| 武器 | 木刀 | TRUE | 10 | 8 |
| 盾 | 木甲の盾 | FALSE | 5 | ○ |

- 種別：`武器` または `盾`
- 通常：`TRUE`、`1`、`○`、`✓` などで収集済み
- 青神器：5〜10の整数、金神器：3〜8の整数
- 補正値が不明な収集済み神器は `○`
- 空欄・`FALSE`・`未収集` は未収集
- 既存の記録と統合し、神器は高い値を優先します
- 収録済みの武器38種・盾33種以外の装備名は取り込めません
